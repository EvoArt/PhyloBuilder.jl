Distances and trees

A small alignment of eight sequences shipped with the tests:

using PhyloBuilder, PhyloIO

aln = readalignment(pkgdir(PhyloBuilder, "test", "fixtures", "small.fa"))
ntaxa(aln), nsites(aln)
(8, 300)

Pairwise distances under the Kimura two-parameter model, with gamma-distributed rates:

d = distances(aln; model=:K80, gamma=0.5)

Trees from the distance matrix, or straight from the alignment:

t_nj    = nj(d; root=:midpoint, ladderize=true)
t_bionj = bionj(aln; model=:TN93, root="s1")
t_upgma = upgma(d)

Drawing a tree

With PlotPhyloTree:

using PlotPhyloTree

p = treeplot(t_nj)
scalebar!(p)
p
savefig("tree.svg", p)

From ASVs to a tree

Amplicon sequence variants from DenoiseDNA, aligned with MSABuilder, then a tree drawn with PlotPhyloTree. seqtab_nochim is the chimera-free sequence table from the DenoiseDNA tutorial.

using DenoiseDNA, MSABuilder, PhyloBuilder, PlotPhyloTree

tree = seqtab_nochim |> align |> nj        # ASVs named ASV1, ASV2, …
p = treeplot(midpoint(tree); layout=:circular)
savefig("asv-tree.svg", p)

Any collection of name => sequence pairs can be passed where an alignment is expected, so nj(align(seqs)) works for plain sequences too.
