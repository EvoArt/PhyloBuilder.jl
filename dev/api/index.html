API

PhyloBuilder — Module
PhyloBuilder

Phylogenetic trees from aligned nucleotide sequences: pairwise distances, UPGMA, WPGMA, neighbour joining and BIONJ. Trees use a bundled PhylogenyIO.PhyloTree until the shared package is registered.

Alignments

PhyloBuilder.Alignment — Type
Alignment(names, sequences)
Alignment(sequences)                     # names "seq1", "seq2", …
Alignment(["name" => seq, …])
Alignment(x)                             # any collection of name => seq pairs

Aligned nucleotide sequences (all the same length). Sequences can be strings or anything whose string is the sequence (e.g. BioSequences' LongDNA). IUPAC ambiguity codes are kept as sets of bases; gaps (-, .) and N/? are missing data.

aln[i] is the ith sequence as a String, aln["name"] looks one up by name, aln[taxa, sites] subsets (by indices, names or masks). Read one with readalignment, write one with writefasta or writephylip.

Distances

PhyloBuilder.DistanceMatrix — Type
DistanceMatrix(names, d::AbstractMatrix; model=:unknown)

A symmetric matrix of pairwise distances with the names of the sequences, as returned by distances. It is an AbstractMatrix{Float64}, so it can be used anywhere a matrix can; d["a", "b"] looks up a pair by name. Pass it to nj, bionj, upgma or wpgma to build a tree.

source
PhyloBuilder.distances — Function
distances(aln; model=:JC69, gamma=nothing, threaded=true, progress) -> DistanceMatrix

Pairwise distances between the sequences of aln. Sites where either sequence has a gap or an ambiguous base are left out of that pair (pairwise deletion).

model is one of

  • :raw – number of differences
  • :p – proportion of sites that differ
  • :JC69 – Jukes & Cantor (1969)
  • :K80 – Kimura (1980) two-parameter, transitions vs transversions
  • :F81 – Felsenstein (1981), unequal base frequencies (A, C, G and T counted over the whole alignment, ignoring ambiguity codes)
  • :TN93 – Tamura & Nei (1993), two transition rates and unequal frequencies
  • :logdet – LogDet (Lockhart et al. 1994; Gu & Li 1996), robust to unequal composition
  • :paralin – paralinear (Lake 1994), LogDet corrected for the composition of each sequence

gamma = α adds gamma-distributed rates across sites with shape α (JC69, K80, F81, TN93). Pairs too divergent for the model (saturated) get Inf. The results match R's ape::dist.dna (pairwise.deletion = TRUE).

Trees

upgma(d; root=nothing, ladderize=false) -> PhyloTree
upgma(aln; model=:JC69, gamma=nothing, kwargs...) -> PhyloTree

UPGMA (average linkage) tree from a DistanceMatrix, or from an alignment via distances. The tree is rooted and ultrametric.

PhyloBuilder.wpgma — Function
wpgma(d; root=nothing, ladderize=false) -> PhyloTree

WPGMA (McQuitty) tree: as upgma, but a merged cluster's distance is the simple mean of its two parts' distances.

source
PhyloBuilder.nj — Function
nj(d; root=nothing, nonnegative=true, ladderize=false) -> PhyloTree
nj(aln; model=:JC69, gamma=nothing, kwargs...) -> PhyloTree

Neighbour-joining tree (Saitou & Nei 1987, in Studier & Keppler's form) from a DistanceMatrix or an alignment (an Alignment, or any collection of name => sequence pairs such as an MSABuilder MSA). The tree is unrooted (drawn from a node with three children) unless root is :midpoint or an outgroup. With nonnegative = true negative branch lengths are set to 0.

source
PhyloBuilder.bionj — Function
bionj(d; root=nothing, nonnegative=true, ladderize=false) -> PhyloTree
bionj(aln; model=:JC69, gamma=nothing, kwargs...) -> PhyloTree

BIONJ tree (Gascuel 1997): neighbour joining that weights each merge by the estimated variance of the distances, which is more accurate when distances are large. Same keywords as nj.
